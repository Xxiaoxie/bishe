# 🎓 毕设急救包（Signal-Easy）

> 面向理工科大学生的**极简数据一键分析 Web 工具**：上传 Excel/CSV，
> 一键生成论文级图表、带逐行中文注释的 Matlab/Python 源码包与答辩说明。

## ✨ 功能一览（对应 PRD）

| 模块 | 说明 |
| --- | --- |
| 文件上传 | 支持 `.xlsx` / `.csv`（自动兼容 UTF-8 / GBK 编码） |
| 数据解析 | 自动识别数值列；多列时默认取前两列（时间 / 幅值），单列也能分析 |
| 数据清洗 | 剔除缺失值 / 非数值行，按时间排序、去重 |
| 采样率估计 | 由时间列间隔推算 Fs；识别不出时按 PRD 默认 `Fs = 1000 Hz` |
| 时域分析 | 原始信号时域波形图 |
| 频域分析 | `scipy.fft` 单边幅值谱，红圈 + 文字标出**主频** |
| 滤波去噪 | 4 阶巴特沃斯低通（截止频率 = 1.5 × 主频，`filtfilt` 零相位） |
| 学术级图表 | 无网格、粗线条、字号 12、**300dpi**，直接可插入论文 |
| 预览水印 | Pillow 在图片正中央叠加半透明斜排水印“预览版 - 支付9.9元解锁高清源码” |
| 自动结论 | 约 100 字的学术分析结论（含实测参数，可直接引用） |
| 源码生成 | 按用户数据定制 `.m` / `.py` 源码，**逐行中文注释**，开箱即跑 |
| 交付打包 | 无水印高清图 ×3 + 双语言源码 + 说明.txt 一键打成 ZIP |

## 🚀 快速开始

```bash
# 1. 安装依赖（建议 Python 3.9+）
pip install -r requirements.txt

# 2. 启动应用
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。
没有数据？直接上传 `示例数据/` 文件夹里的两份 CSV 试一试：

* `示例数据_含时间列.csv` —— 标准场景（时间列 + 幅值列，内含 3 个缺失值演示清洗）
* `示例数据_仅幅值列.csv` —— 无时间列场景（自动按默认 Fs = 1000 Hz 处理）

## ❓ 常见问题

* **图表中文变方框？** 项目已内置开源中文字体（`fonts/NotoSansCJKsc-Regular.otf`），
  本地和云端（含 Streamlit Cloud 的 Linux 容器）都会优先使用，理论上不会出现方框。
* **采样率显示 1000 但我明明有采样率？** 时间列必须**单调递增且基本等间隔**
  才会被识别；“0,1,2,3…”这类序号列会被当作样本序号而回退默认值。
* **多列数据取了哪两列？** 前**两个**数值列（80% 以上为数字即算数值列），
  页面“数据预览”里会明确显示所选列。
* **上传的数据会被保存吗？** 不会，全部在内存中分析，会话结束即消失。
